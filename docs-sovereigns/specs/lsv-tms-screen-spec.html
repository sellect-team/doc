문서 개요

이 문서의 범위와 표기

1단계 구축 대상 화면을 화면 단위로 정의하며, 개발 착수와 검수의 기준 문서로 사용합니다.

범위

포함하는 것

  • 화면 목록과 ID 체계
  • 화면별 시안과 구성 요소
  • 동작 · 예외 · 화면 전이
  • 권한별 노출 · 제어 규칙
범위

포함하지 않는 것

  • 최종 비주얼 디자인 규격
  • API 명세 · 데이터 스키마
  • 비기능 요구(성능 · 보관)
  • 2단계 확장 화면
표기

ID와 권한

  • 화면 ID는 SCR-000, 메뉴 단위 10 간격
  • 권한 3단계 - 전역 관리자 · 골프장 관리자 · 조회 전용
  • 필수 입력은 별표(*) 표기
시안

읽는 법

  • 1920 x 1080 화면을 축소한 비율
  • 수치 · 카트 번호는 예시 데이터
  • 임계값은 협의 전 기준안
선행 확정 필요 - 수집 주기, 보관 기간, 코스 좌표 확보 방법, 단말 사양이 확정되면 해당 화면의 표시 항목과 갱신 주기를 반영해 개정합니다.
