문서 개요

이 문서의 범위와 표기

1단계 구축 대상 화면을 화면 단위로 정의하며, 개발 착수와 검수의 기준 문서로 사용합니다.

범위

포함하는 것

  • 화면 목록과 화면 ID 체계
  • 화면별 영역 구성과 구성 요소
  • 주요 동작과 화면 전이
  • 권한별 노출 · 제어 규칙
범위

포함하지 않는 것

  • 비주얼 디자인(색 · 여백 최종안)
  • API 명세와 데이터 스키마
  • 비기능 요구(성능 · 보관 기간)
  • 2단계 확장 화면
표기

규칙

  • 화면 ID는 SCR-000 형식, 메뉴 단위로 10 단위 부여
  • 권한은 전역 관리자 · 골프장 관리자 · 조회 전용 3단계
  • 수치와 임계값 표기는 협의 전 기준안
  • 와이어프레임은 영역 배치 확인용
선행 확정 필요 - 수집 주기, 보관 기간, 코스 좌표 확보 방법, 단말 사양이 확정되면 해당 화면의 표시 항목과 갱신 주기를 반영해 개정합니다.

공통 규칙

공통 레이아웃

모든 화면은 상단 바 · 좌측 메뉴 · 본문 3영역을 공유하며, 관제 화면만 전체 화면 모드를 지원합니다.

상단 바 - 로고 · 골프장 선택 · 알림 배지 · 계정고정
좌측 메뉴대시보드 / 관제 / 운행 / 차량 / 정비 / 설정

권한에 따라 항목 노출
본문 영역화면별 콘텐츠. 상단에 화면 제목과 검색 · 필터 영역을 두고 그 아래 목록 또는 지도를 배치합니다.
전체 화면 모드에서는 좌측 메뉴가 숨겨집니다
영역 규칙
  • 상단 바 - 골프장 선택(전역 관리자만), 미확인 알림 수, 계정 메뉴
  • 좌측 메뉴 - 권한이 없는 메뉴는 노출하지 않음
  • 본문 - 화면 제목, 필터, 콘텐츠 순서 고정
공통 동작
  • 세션 만료 시 로그인 화면으로 이동하고 직전 화면을 기억
  • 실시간 화면은 연결 상태를 표시하고 끊기면 재연결
  • 대형 화면(DID) 출력을 위한 다크 모드 전환 제공
해상도
  • 기준 1920 x 1080, 최소 1366 x 768
  • 관제실 대형 화면 4K 출력 시 배율 조정
