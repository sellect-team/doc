문서 개요

이 문서를 쓰는 방법

화면 목록만으로는 알 수 없는 사용 순서와 역할 간 인계 지점을 정의해, 개발 우선순위와 검수 시나리오의 기준으로 사용합니다.

목적

업무 순서로 검증

기능이 아니라 하루의 업무 순서대로 따라가며 빠진 단계와 화면을 찾습니다.

구성

역할 · 시나리오 · 화면

역할 5개와 시나리오 7개를 정의하고, 각 단계에 사용하는 화면 ID를 함께 표기합니다.

활용

검수 시나리오로 재사용

각 시나리오는 인수 시험 항목으로 그대로 사용할 수 있도록 단계와 결과를 기술합니다.

표기 - 화면 ID(SCR-000)는 화면정의서와 동일합니다. 시간 · 임계값 표기는 협의 전 기준안이며 확정 후 갱신합니다.

역할과 권한

사용자 역할 5개

역할은 권한 등급 3단계와 연결되며, 같은 화면이라도 역할에 따라 가능한 동작이 다릅니다.

전역 관리자

본사 운영 담당

여러 골프장을 함께 관리합니다. 코스 · 차량 · 계정 등 기준 정보를 설정합니다.

  • 주 사용 화면 - SCR-080, 130, 140
골프장 관리자

현장 운영 책임

담당 골프장의 운영 현황과 리포트를 확인하고 차량 별칭을 관리합니다.

  • 주 사용 화면 - SCR-010, 050, 060
관제 운영자

관제실 상시 근무

라운드 진행 중 실시간 화면을 지켜보며 이상 상황을 최초로 인지합니다.

  • 주 사용 화면 - SCR-010, 020, 030
정비 담당자

차량 정비 · 점검

알림을 받아 조치하고 정비 이력과 소모품 교체를 기록합니다.

  • 주 사용 화면 - SCR-090, 100, 110, 120
2단계

경기 진행 요원

코스 내 진행을 담당합니다. 지연 · 이탈 알림 수신과 카트 안내가 2단계 대상입니다.

  • 연계 기능 - 지연 알림, 메시지 템플릿
비계정

대형 화면 열람

관제실 DID는 조회 전용 계정으로 대시보드만 상시 표시합니다.

  • 주 사용 화면 - SCR-010(전체 화면)
