포털 기능 - 검색과 순서 관리

03 · Portal

문서가 늘어날 것을 감안해 찾는 기능과 정리하는 기능을 추가했습니다.

기능동작
문서 검색 제목 · 설명 · 카테고리 · 버전에 더해 각 문서의 페이지 제목까지 검색합니다. 예를 들어 "문서 파서"를 검색하면 해당 페이지가 있는 문서가 나오고, 칩을 누르면 그 페이지로 바로 이동합니다.
정렬 기본 순서 / 최신 수정순 / 이름순 중에서 선택합니다.
순서 편집 "순서 편집"을 누르면 카드를 끌어서 순서를 바꿀 수 있습니다. 바꾼 순서는 내 브라우저에만 저장되고, "기본 순서로 내보내기"를 누르면 전사 기본 순서로 반영할 설정을 복사해 줍니다.
전사 기본 순서 저장소의 docs/order.json에 적힌 순서가 모두에게 보이는 기본 순서입니다. 현재는 회사소개서 → 솔루션 소개서 → 고객 배포용 → SRL → PoC 레퍼런스 → 제안서 템플릿 순입니다.
결과 개수 표시 필터 아래에 현재 보이는 문서 수를 표시합니다.
순서를 바꾸고 싶으시면 포털에서 끌어 옮긴 뒤 "기본 순서로 내보내기"를 눌러 알려 주세요. 반영해 드리겠습니다.
