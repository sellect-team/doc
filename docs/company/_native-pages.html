01사내 데이터

실적 셀프 조회

과제

실적이 시스템별로 흩어져 있고, 조회 요청이 본사 담당자에게 집중되어 대기가 발생

적용

무선 · 유선 상품군별 실적을 대화형으로 조회하고, 팀장 이상 관리자용 현황 요약 뷰 제공

효과

요청 대기열 감소 · 현황 파악 시점 단축 · 조회 이력 전건 기록

02사내 문서

사내 문서 챗봇

과제

사내 문서 2,000여 건이 쌓여 탐색에 시간이 들고, 열람 권한이 달라 통합 검색이 어려움

적용

사내 문서 시스템을 API로 연동하고, 권한 범위 내 문서만 답변에 활용

효과

문서 탐색 시간 단축 · 권한 밖 노출 없음 · 답변 근거를 원문으로 확인

03산출물 공유

대시보드 공유 · SDK

과제

개인이 만든 분석 결과물이 파일로 흩어지고, 공유 시 열람 범위를 통제할 수단이 없음

적용

HTML 산출물을 플랫폼에 등록하고, 권한 관리 기반으로 링크 공유

효과

분석 결과물이 조직 자산으로 축적 · 중복 제작 감소

04외부 시스템

도매 에이전트 연동

과제

도매 업무가 별도 시스템이라 분석 도구와 분리되고, 확인한 내용이 액션으로 이어지지 않음

적용

aisight AI 기능을 API로 제공해 고객사 도매 에이전트 시스템에 탑재

효과

업무 화면에서 바로 인사이트 확보 · 분석 이후 액션까지 연결

8월 구축을 완료하고 일부 조직이 파일럿으로 사용 중입니다. 문서 접근은 사내 문서 시스템의 기존 권한 체계를 그대로 따릅니다.
