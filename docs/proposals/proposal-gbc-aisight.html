태블로에도 없는 층.

지표 거버넌스

같은 이름 = 같은 숫자.

비용 구조의 전환

태블로 좌석 라이선스는 aisight로 대체되고, 건당 개발비는 조립으로 흡수됩니다. 요청이 늘어도 비용이 늘지 않는 구조.

한계비용 최소의 구조.

포탈은 그대로

기존 커스텀 포탈에 임베드되어 사용자 동선이 바뀌지 않습니다. 전환 프로젝트 최대 리스크의 제거.

가치 ① 심화 - "LLM에게 시키면 되지 않나요?"

02 · Value

맞습니다, LLM도 대시보드 코드를 만들어 줍니다. 하지만 만들 때 한 번과 운영하며 매일 고치는 일은 다른 문제입니다.

관점LLM 코드 생성으로 만들 때aisight Studio로 만들 때
제작 시간프롬프트 → 코드 → 실행 환경 준비 → 디버깅. 시도마다 결과 편차가 큼 AI가 지표·차트 초안을 먼저 - 말로 시키거나 위젯을 조합해 수 분, 데이터 연결·권한은 이미 끝난 상태
화면 규격만들 때마다 생김새가 다름 - 담당자마다, 세션마다 제각각 모든 대시보드가 같은 규격·디자인 시스템 - 누가 만들어도 GBC 표준 화면
세부 수정"여백만 조금 줄여줘"를 말로 반복 - 다시 생성될 때마다 엉뚱한 곳이 바뀌는 리스크 해당 위젯만 클릭해 직접 미세 조정 - 나머지는 그대로, 결과가 예측 가능
데이터 연결코드마다 DB 연결·권한·보안을 다시 만들고 다시 검증 검증된 연결과 권한 체계 위에서 - 지표 사전과 자동 연동, 숫자가 항상 같음
유지보수생성된 코드 덩어리 하나하나가 관리 대상 - 쌓일수록 부채 저장되는 것은 위젯 설정뿐 - 플랫폼 업그레이드가 전체 화면에 한 번에 적용
LLM은 aisight 안에서 제자리에 씁니다 - 코드 생성이 아니라 질의 · 요약 · 리포트 초안에.

aisight · GBC Performance Summary (구성 화면)AI 어시스턴트

구성 화면. 열자마자 왼쪽 AI 어시스턴트가 변곡·원인 후보·추천 질문을 제시하고, 필터는 지금 화면과 같습니다. 상단에 "Claude로 분석" 버튼. (수치는 예시)

자연어 질의 ASK

질의 성격에 따라 알맞은 모델로 보내는 하이브리드 LLM 라우팅 - aisight가 금융·제조 현장에서 상용 운영 중인 기술입니다.

자동 요약 브리핑 BRIEF

열면 "하락 전환" 같은 변곡부터 짚고, 원인 후보를 수치와 함께 제시합니다. 이어서 물을 추천 질문까지 붙습니다 - 회의 전 10분이 사라집니다.

이상 신호 알림 WATCH

임계치·추세 이탈을 플랫폼이 감시해 담당자에게 먼저 알립니다. 대시보드를 열지 않은 날에도 데이터가 말을 겁니다.

태블로에도, 단순 웹 대시보드에도 없는 층입니다 - 분석가를 거치지 않고 답을 얻는 경로.

가치 ② 심화 - 화면에서 분석하고, 개인 AI로 이어갑니다

02 · Value

분석의 기본은 대시보드 안 AI 어시스턴트입니다. 더 이어가고 싶을 때는 aisight가 MCP(모델 연결 표준)로 열려 있어 쓰던 개인 Claude·사내 AI가 바로 연결됩니다.

기본은 화면 안에서 BUILT-IN

브리핑·질의·추천 질문까지, 분석의 기본 동선은 대시보드를 떠나지 않습니다. 앞 장의 AI 어시스턴트가 그 화면입니다.

aisight가 곧 MCP 연결점 OPEN

Claude Desktop 등 MCP를 지원하는 AI라면 aisight의 지표·데이터에 바로 연결해 대화합니다. MCP는 공개 1년 만에 OpenAI·Microsoft·Google이 채택하고 Linux Foundation이 관리하는 업계 표준 - 특정 AI에 묶이지 않습니다.

이어갈 때는 버튼 하나 HANDOFF

"Claude로 분석"을 누르면 보던 화면의 필터·기간·지표가 질문에 미리 담긴 채 개인 Claude가 열립니다. 조회는 본인 권한 범위, 질의는 감사 로그에 - 통제는 그대로입니다.

"Claude로 분석" - 이어가기 (예시 화면)MCP 연결

예시 화면. 버튼을 누르면 질문이 미리 입력된 Claude Desktop이 별도 창으로 열리고, MCP로 aisight 데이터를 본인 권한 범위에서 조회합니다.

이 연동 패턴은 삼성전자 마케팅 현장 검증을 거친 방식입니다 - 데모에서 실제로 보여 드립니다.

통제 01DICTIONARY

표준 지표 사전

Studio의 "데이터 지식" 메뉴가 지표의 정의·산식·출처를 한곳에 모으고, 조직 인증을 받은 데이터와 지표만 표준으로 표시됩니다. "eStore 전환율"이 법인마다 다르게 계산되는 일이 구조적으로 사라집니다.

예시

"eStore 전환율 = eStore Revenue 주문 / Clicks" - 산식이 위젯에 자동 표기

지표 정의의 단일 출처(Single Source).
통제 02ACCESS

권한과 행 수준 보안

역할·조직 기준으로 화면 접근을 통제하고, 데이터는 행 단위로 필터링합니다. 유럽 담당자는 유럽 데이터만, 경영진은 전체를 - 같은 대시보드에서.

예시

같은 대시보드를 열어도 유럽법인 담당자에게는 유럽 행만 보입니다

AI 질의도 같은 권한 범위 안에서만 답합니다.

이력과 감사

누가 어떤 대시보드를 만들고 고쳤는지, 어떤 질의를 했는지 전부 기록됩니다. 감사 대응과 데이터 품질 관리의 근거가 자동으로 쌓입니다.

예시

"이 숫자 누가 바꿨죠?"에 변경 이력 화면으로 바로 답합니다

셀프서비스를 열어도 책임 추적은 유지됩니다.
